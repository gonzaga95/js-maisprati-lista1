# Lista de Exercícios de Introdução à Lógica de Programação com JavaScript

Este repositório contém a primeira lista de exercícios para iniciantes em lógica de programação utilizando JavaScript. Os exercícios abordam conceitos básicos como estruturas de controle (if/else, switch/case), loops (for, while) e manipulação de dados.

A lista é parte da formação Desenvolvedor Full-stack da instituição [Mais Pra Ti](https://www.maisprati.com.br/). 

## Como Executar os Exercícios

Para executar os exercícios, você precisará ter o [Node.js](https://nodejs.org/) instalado em seu sistema. Após a instalação, siga os passos abaixo:

1.  Clone este repositório para sua máquina local:

    ```bash
    git clone <URL_DO_REPOSITÓRIO>
    ```
2.  Navegue até o diretório do exercício que você deseja executar:

    ```bash
    cd js-lista-1-exercicios/exercicio-N
    ```

    (Substitua `N` pelo número do exercício, ex: `exercicio-1`, `exercicio-2`, etc.)
3.  Execute o arquivo JavaScript utilizando o Node.js:

    ```bash
    node ex-N.js
    ```

    (Substitua `N` pelo número do exercício, ex: `ex-1.js`, `ex-2.js`, etc.)
